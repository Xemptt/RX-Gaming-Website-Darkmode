MAJOR CORRECTIONS
- Fixed the ServerCounter props mismatch that prevented production builds.
- Replaced the wrong-method checkout endpoint with a real POST flow.
- Corrected Tebex API URLs and replaced permanent loading/demo products with
  live, realm-filtered catalogs, real currencies and useful error/retry states.
- Added Java username and trusted customer IP handling, server-side package
  and quantity validation, same-origin checks, safe redirect validation,
  streamed request-size limits and cancellation/time limits.
- Retained cart contents across cancellation/return; synchronized upstream
  baskets on retry to avoid adding the same packages again.
- Validated persisted carts and constrained quantities/currencies; handled
  disabled storage and browser-back restoration of checkout controls.
- Removed pretend voucher redemption and unsupported payment-success claims.
- Repaired documents, missing store route, invalid-route handling, assets,
  merchant links, realm addresses/ports, branding, metadata and sitemap.
- Server status now queries fixed approved addresses with bounded requests,
  caching, and distinct offline versus unavailable states.
- Improved narrow layouts, focus/labels, menu Escape behavior, hidden
  accordion content, contrast, reduced motion and cursor fallback.
- Updated Next.js from 16.1.6 to 16.3.8; final npm audit reports zero findings.
- Hardened Docker build context/runtime and documented public SITE_URL
  at build time, runtime token/proxy configuration and domain rebuilds.

VERIFICATION LIMITS
No real payment was made. Checkout integration tests mock Tebex; real payment,
receipt, cancellation, authentication-provider and in-game delivery behavior
must be confirmed using the merchant's deployment/payment test workflow.
Local checkout deliberately refuses an untrusted/missing customer IP and
offers the official hosted store. Vercel or an explicitly configured trusted
reverse proxy is required for integrated production checkout.
Docker was reviewed but not built/run because Docker is unavailable here.
The changes are local files; the public production site was not deployed.

OPTIONAL FOLLOW-UP
